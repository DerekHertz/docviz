docviz

See how documented code behaves — diagrams inline on any page, simulations on demand. Runs on your own Claude Code or Codex login.

1Start the helper

In a terminal where claude or codex is logged in (WSL works):

docviz serve

Or run /docviz inside Claude Code with the docviz plugin installed. It prints a pairing code.

3Learn how you like things explained

Here’s debounce(fn, wait) explained four ways. Pick the one that clicks — your cards start there.

Real identifiers always appear, whatever you pick. Docviz keeps learning: “Simpler” and “More detail” on a card nudge your depth — you’ll see it happen, with undo.

4Spending

Every card shows what it cost, and the side panel keeps a running total. Docviz stops starting new work once today’s spend reaches your budget.

$0 = no cap

Prices are what the same calls cost on the API. On a Claude or ChatGPT subscription you aren’t billed per call — it comes out of your plan’s usage limits instead. Codex prices are estimated from token counts.
